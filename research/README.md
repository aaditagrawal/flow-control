# Research artifacts

This directory contains authored evidence summaries used to scope compatibility with the LoFree Flow Lite 84.

- `FLOW_LITE_84_TECHNICAL_REFERENCE.md`: consolidated hardware identity, report protocol, flash map, capabilities, lighting/custom-map findings, macOS permission/signing diagnosis, safety boundaries, and live firmware `v1.66` verification results.
- `lofree-windows-driver/PROVENANCE.md`: hashes and acquisition links for locally inspected vendor material.

The local workspace may also contain downloaded web assets, manuals, an official Windows package, archives, and extracted binaries. They are intentionally ignored and are not part of the public repository. Re-fetch and hash upstream artifacts before relying on them; do not redistribute or execute the Windows installer as part of a build.

These documents are reference material, not application source. See [the repository artifact policy](../docs/evidence-and-research.md).
